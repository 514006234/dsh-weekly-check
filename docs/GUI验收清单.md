# 重启 DSH 后的验收清单（面板化改造）

背景：把两个「侧边栏底部抽屉」升级成「中间整列面板」，并新增中央仪表盘。
客户端 bundle 在启动时快照——**必须完全重启 DSH（关闭再打开）**才能看到变化。

## 1. 侧边栏图标行（panellist）——本轮最关键的观察点

重启后，看**侧边栏图标行**是否出现三个图标（图标行由框架的 `sidebar.panellist` 槽渲染）：

- 📊 周榜
- 🧰 工作台
- 📈 仪表盘

| 结果 | 含义 | 下一步 |
|---|---|---|
| 三个图标都在，点击切换中间面板 | 改造完全成功 | 继续第 2 步 |
| 图标行整行不出现 | 框架文档承诺了此机制，但**尚无第三方先例**——需要我们改用保底入口 | 用第 3 步的底部按钮，反馈给开发侧 |
| 图标出现但点击没反应 | panellist→selectPanel 的联动未生效 | 同上，用保底入口并反馈 |

## 2. 面板本体（点图标或保底按钮进入后）

- [ ] 内容是**中间整列宽度**（不再挤在侧边栏底部的狭长抽屉里）
- [ ] 卡片网格自适应（宽屏多列、窄屏单列）
- [ ] **不遮挡对话**：面板是流内布局，切回对话（点侧边栏会话）立刻回来
- [ ] 周榜面板：TOP10 星数/涨星、免费模型、赞助位（有赞助时）
- [ ] 工作台面板：控制室、项目卡片、加星、开新会话（原能力都在）
- [ ] 仪表盘面板：周榜 TOP6 卡、免费模型状态卡、最近会话卡（点开即入会话）、快捷动作、支持本项目卡
- [ ] 数据拉不到时显示中文失败提示 + 重试按钮，**不白屏**

## 3. 保底入口（侧边栏底部旧按钮）

旧的 `⌘ 工作台` / `📊 周榜` 按钮**保留**了，行为改为：
- 正常情况：点击 → 切到对应的中间面板（不再弹抽屉）
- 降级情况（框架 layout face 不可用）：点击 → 打开旧抽屉（原逻辑）

## 4. 出问题时的撤销（一条命令）

```bash
cd D:\ds工作区\dsh-weekly-check
node tools/deploy-panel.mjs --check                 # 看状态
node tools/deploy-panel.mjs --uninstall --pkg dsh-dashboard   # 单个撤
node tools/deploy-panel.mjs --uninstall --pkg all             # 全撤
```

然后完全重启 DSH。profile 的 `package.json.bak` 是写盘前的自动备份，可手动还原。
